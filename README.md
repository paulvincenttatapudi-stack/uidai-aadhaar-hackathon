# UIDAI Aadhaar Data Analysis – Hackathon Project

## 📌 Problem Statement
Analyze Aadhaar enrolment data to identify trends, demographic patterns, and anomalies that can help UIDAI in policy-making and operational improvements.

## 📊 Dataset
- Aadhaar Enrolment API Data (CSV files)

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📈 Analysis Performed
- Monthly enrolment trends
- State-wise top enrolments
- Demographic distribution
- Spike detection in enrolment patterns

## 📷 Visualizations
- Monthly trends
- Demographic pie charts
- Top states analysis
- Spike detection graphs
